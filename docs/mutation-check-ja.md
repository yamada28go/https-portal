# P1 Mutation検証

## 実装と実施状態

M01〜M08の自動検証を `dev/check_p1.rb` に実装した。**従来83例に対するM01〜M05は利用者実行ログで検知・復元成功を確認済み。C-07/C-08追加後の113例とM06〜M08は実行待ち。** スキップやpendingで完了扱いにしない。

検証は一時ディレクトリにソースとspecを複製して行う。元のチェックアウトの製品コードは書き換えない。複製上で通常成功→1か所変更→指定した1例が失敗→元データ復元→同じ1例が成功、最後に全113例成功を検査する。単なる起動エラーや対象例0件は成功扱いにしない。

| ID | 一時的な変更 | 失敗すべきケース |
|---|---|---|
| M01 | HTTP 301を302へ | H01 |
| M02 | X-Forwarded-Protoを削除 | R02 |
| M03 | auth_basic_user_fileを削除 | A01 |
| M04 | 更新判定の > を >= へ | C05 |
| M05 | HTTPS転送の既定307を302へ | R04 |
| M06 | timeout指定を120から121へ | C-07-01 |
| M07 | reload失敗時にkill指定の条件を削除 | C-08-01 |
| M08 | 証明書mvのforceをfalseへ | C-07-05 |

## 実行

環境構築済みのプロジェクトルートからPowerShellで実行する。

```powershell
.\dev\dev.ps1 P1
```

直接実行する場合：

```powershell
docker compose -p https-portal-dev -f dev/compose.dev.yaml run --rm test bundle exec ruby dev/check_p1.rb
```

このコマンドは構文確認、全113例の3 seedでの実行、各spec単独実行、Mutation検証をまとめて行う。ネットワークなし・Gem読み取り専用のtestサービスを使う。

日時、コマンド、変更箇所、失敗メッセージ、終了コード、復元後の結果を `dev/test-results/p1-check.log` に保存する。このログはGit対象外。既存ログは実行ごとに上書きするため、レビューに使う結果は別途保管する。ローカルのチェックアウト／一時パスはログ中で匿名化する。

実行後に実施環境、113例の結果、M01〜M08の検知と復元結果、レビュー状況を本書へ追記する。現時点で人による期待値レビューとP0成果照合は未完了。
